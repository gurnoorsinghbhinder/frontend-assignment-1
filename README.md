# 📣 Brevo Campaigns Page

A responsive, modal-powered **campaign creation UI** inspired by Brevo (formerly Sendinblue). This project showcases frontend skills using pure HTML, CSS (with custom variables), and vanilla JavaScript — ideal for portfolio display and component-driven web development practice.

---

## 🚀 Features

- 🎯 **Campaign Dashboard UI** with modular layout
- 🧩 **Modal system** for campaign creation (Email, SMS, WhatsApp, Web Push)
- ⚙️ **Responsive design** — works across desktops, tablets, and mobiles
- ✨ Clean button interactions and layout using Flexbox & Grid
- 🎨 Themed using CSS variables for scalable styling

---

## 🧱 Tech Stack

- **HTML5** — semantic markup
- **CSS3** — variables, flexbox, grid, and media queries
- **JavaScript (ES6)** — for modal control logic
